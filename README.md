# STREET WAR — Operation Broken City

A self-contained, browser-playable top-down urban pursuit and combat game.

## Play
Open `index.html` in a modern browser, or deploy this repository as a static site on Vercel.

- **WASD / Arrow keys:** steer and drive
- **Space:** fire
- **Shift:** nitro boost
- **R:** restart after a defeat
- Mobile: on-screen directional pad and fire button

## Deploy on Vercel
Import this repository into Vercel. It is a static HTML project; no build command or environment variables are required. Set the output directory to the project root if prompted.

## Technical notes
- Canvas 2D rendering; no runtime dependencies or build step.
- Responsive desktop and touch controls.
- Waves, pursuit AI, hostile fire, vehicle integrity, score, nitro, particle effects.
